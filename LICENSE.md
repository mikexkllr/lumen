# Lizenzen

Lumen ist mehrfach lizenziert. Jede Datei fällt unter die Lizenz des Ordners, in dem sie liegt:

| Pfad | Lizenz | Datei |
|---|---|---|
| `packages/engine`, `packages/cli` | MIT | `packages/*/LICENSE` |
| `apps/web`, `apps/server` | AGPL-3.0-or-later | `apps/*/LICENSE` |
| `content/` | CC BY-SA 4.0 | `content/LICENSE` |
| Name „Lumen“ und Logo | Markenrichtlinie | `TRADEMARK.md` |

Werkzeuge im Repository-Wurzelverzeichnis (Konfiguration, CI, `deploy/`) stehen unter MIT.
